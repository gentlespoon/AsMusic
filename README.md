# 🎧 AsMusic

## 🚧 WORK IN PROGRESS

Purely 🤖 vibe-coded music players compatible with Navidrome/Subsonic servers.

The React / Capacitor shell lives under **`apps/web/`**; shared TypeScript is in **`packages/`** (`@asmusic/core`, `@asmusic/ui`, `@asmusic/platform-web`, `@asmusic/platform-capacitor`, `@asmusic/shell`). Native shells remain at the repo root: **`ios/`**, **`android/`**, **`desktop/`**.
